What each workflow contains
Problem statementtask_desc.json provides the structured task, application, domain, description, deliverables, workspace, references, and initial state.
Human-readable task overviewtask_overview.pdf packages the task for convenient review.
Reference and source materialinput_files/ contains the files and assets provided to the operator.
Gold outputoutput_files/ contains the deliverables produced during the walkthrough.
Evaluation criteriarubrics.json describes the requirements used to judge task completion, and marks which of them execute against the delivered file.
Human walkthroughclip.mp4 records the complete on-screen execution of the task at a constant frame rate.
Interaction traceevents.json contains synchronized mouse and keyboard events, each carrying the clip frame it occurred on and the accessibility role and name of the element it acted on; frame_events.json provides the same stream grouped by frame.
Narrationnarration.json provides timestamped descriptions of each moment, stating what was done and what it was for.
Recording metadatametadata.json includes duration, frame rate, frame count, event count, step count, platform, display geometry, and whether the time base is trusted.
Derived computer-use representationscale-cua-format/ contains trajectory annotations and step images for frame/action-based use.
